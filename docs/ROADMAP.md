# Roadmap — этапы проекта

Порядок: **сначала весь backend → Swagger (тестирование API) → frontend → деплой → мобилка.**
Каждый этап заканчивается рабочим результатом, тестами и коммитом в ветку `kholid`.
Подробно, какие файлы и в каком порядке пишем, — в [CODING-PLAN.md](CODING-PLAN.md).

## ЧАСТЬ A — BACKEND

### Этап 0 — Подготовка
- [x] Установить PHP 8.4, Composer, PostgreSQL 17
- [x] Перенести Next.js в `frontend/`, создать папку `backend/`
- [x] Документация в `docs/`
- [x] Установить Laravel 13 в `backend/`, БД `bakht_stroy`, `.env` / `.env.example`
- [x] Пакеты, Pint, Larastan, Pest, CI в GitHub Actions
- [x] Каркас модулей, единый формат ошибок, Swagger UI `/api/documentation`
